# 微信聊天记录导出工具

把**电脑版微信**里的一对一聊天记录导出成 Word 文档（可选同时导出 TXT），
图片、视频、文件、语音自动归集到同名文件夹。

> 仅用于导出**你自己账号**在本机已有的聊天记录。请勿用于导出他人数据。

## 下载安装

不用装 Python，直接下安装包：

**[⬇ 微信导出工具 安装包（v1.0.0）](https://github.com/zhihui09/wechat-chat-exporter/releases/latest)**

下载 `WeChat-Exporter-Setup-1.0.0.exe`，双击安装，桌面会出现快捷方式。
安装到 `%LOCALAPPDATA%\微信导出工具`，不需要管理员；卸载运行目录下的 `卸载.cmd`。

## 功能

- 只列一对一联系人（好友 / 陌生人），自动排除群聊、公众号、系统号
- 按拼音首字母分组，支持拼音缩写搜索（如「瞿瑞海」输 `qrh`）
- 导出真实进度 + 预计剩余时间，随时可取消
- 导出完成自动打开文件夹并选中产物
- 图片 / 视频 / 文件 / 语音自动归集
- 启动自检：系统、权限、微信目录、微信进程、输出目录逐项报告
- 免安装依赖：打包后单个安装包，目标机器不需要 Python

## 环境要求

- Windows 10 / 11，64 位
- 电脑版微信 4.x（3.9 及更早版本未验证）
- 运行时需要管理员权限（读取微信进程内存里的数据库密钥）

## 使用

1. 登录电脑版微信，停留在能看到聊天列表的界面
2. 双击运行 `微信导出工具.exe`，UAC 弹窗点「是」
3. 左侧选联系人，点「导出」
4. 产物默认输出到 `文档\微信导出\<联系人>_聊天记录.docx`

## 从源码构建

```bash
pip install pyinstaller
python -m PyInstaller 微信导出工具.spec --noconfirm
```

产物在 `dist/微信导出工具/`。整包使用，`exe` 与 `_internal` 必须放在一起。

打安装包：

```bash
# 1) 把 dist/微信导出工具 打包成 payload.zip
# 2) 构建安装器
python -m PyInstaller 安装包.spec --noconfirm
```

## 项目结构

```
微信导出App.pyw        # GUI（Tkinter）
wxexport_core.py       # 解密、联系人、消息收集、Word/TXT 输出
微信导出工具.spec       # 主程序打包配置
安装器.py / 安装包.spec  # 安装包构建
vendor/                # 第三方微信数据库解密库（WTFPL）
```

## 说明

- 解密出来的数据库只放在系统临时目录，程序退出时清理
- 程序没有上传功能，导出全程在本机完成
- 不读朋友圈、不读群聊，只读所选联系人的一对一消息
